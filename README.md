# Komşu Matkap Saat Denetimi

Resmi daire değildir. Resmi daireymiş gibi durur. Komşunun duvarı delme hakkını saat, kat, bahane ve «bir dakika bitti abi» katsayısıyla ölçer. Çıktı bağlayıcı değildir. Çıktı yine de duvara asılabilir.

Patates yoktur. Patates arayanlar yanlış kata çıkmıştır.

## Ne işe yarar

Hiçbir şeye. Ama şunları hesaplar:

- Matkap kaçıncı dakikada komşuluk sözleşmesini deldi
- Ceza birimi: ince belli çay ve olağanüstü apartman toplantısı
- «Raf asıyorum» bahanesinin inandırıcılık puanı
- Sessiz saat ihlalinde otomatik tutanak

## Kurulum

```bash
python3 matkap_denetim.py --saat 23 --dakika 47 --kat 4 --bahane raf
```

Bağımlılık yoktur. Python 3 yeter. Matkap gerekmez. Duvarın üzülmesine de gerek yoktur.

## Örnek hüküm

Gece 23:00, 47 dakika, 4. kat, bahane «raf» ise daire şunu yazar: sessiz saat ihlali, 3 çay ve 1 apartman toplantısı. İtiraz mercii mutfak masasıdır. Mutfak masası da matkap sesinden duymaz.

## Copilot notu

Bu depoda `.github/copilot-instructions.md` vardır. Copilot'a «sessiz saat kaçta biter» diye sorarsan, o da çay cezası kesmeye çalışır. Konuşma tek taraflıdır. Copilot cevap vermezse matkap susmuş demektir, kutla.
